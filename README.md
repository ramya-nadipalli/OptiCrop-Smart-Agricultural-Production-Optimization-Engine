# OptiCrop: Smart Agricultural Production Optimization Engine

## Overview
OptiCrop is a Machine Learning-based crop recommendation system that helps farmers select the most suitable crop based on soil nutrients and environmental conditions. The system analyzes agricultural parameters and predicts the optimal crop for cultivation.

## Features
- Crop recommendation using Machine Learning
- Web-based user interface
- Fast crop prediction
- Data-driven agricultural support
- Easy-to-use application

## Technologies Used
- Python
- Flask
- Machine Learning
- Scikit-learn
- Pandas
- NumPy
- HTML
- CSS

## Dataset
The model is trained using agricultural data containing soil and environmental parameters such as:
- Nitrogen (N)
- Phosphorus (P)
- Potassium (K)
- Temperature
- Humidity
- pH
- Rainfall
