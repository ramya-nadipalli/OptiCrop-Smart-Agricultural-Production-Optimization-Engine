About the Project

What OptiCrop does and how it was built

OptiCrop is a machine learning-powered crop recommendation system I built to solve a real problem — farmers often don't have access to data-driven advice on what to grow. Most decisions are made on tradition or guesswork, which leads to poor yields and wasted resources.

The system takes 7 soil and climate inputs (N, P, K, temperature, humidity, pH, rainfall) and passes them through a Logistic Regression model trained on 2,200+ real agricultural records. The model predicts the best-suited crop with over 95% accuracy across 22 crop types.

The backend is built with Python and Flask, and the frontend uses plain HTML, CSS, and JavaScript. The model was trained in a Jupyter Notebook using Scikit-learn and saved as a pickle file for deployment.
